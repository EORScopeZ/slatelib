Slate UI Documentation

A modern, ultra-responsive monochrome UI library for Roblox with top-pill navigation, left-to-right swipe transitions, and 1,200+ solid filled Fluent system icons.

Overview

Slate provides a clean obsidian dark aesthetic with pure white accents, fluid swipe page transitions, custom icon colors, and universal executor compatibility.

Installation

Load Slate directly via HTTP using loadstring:

LUAU 
local slate = loadstring(game:HttpGet("https://raw.githubusercontent.com/EORScopeZ/slatelib/main/Slate.lua"))()

Quickstart

Here is a complete setup script demonstrating tabs, toggles, sliders, dropdowns, and notifications:

LUAU 
local slate = loadstring(game:HttpGet("https://raw.githubusercontent.com/EORScopeZ/slatelib/main/Slate.lua"))()

local window = slate:CreateWindow({
    name = "slate",
    subtitle = "monochrome edition",
    icon = 136661212895058,
    theme = "Default",
    sidebarLayout = false,
})

local main_tab = window:CreateTab({
    name = "main",
    icon = "home",
})

main_tab:CreateSection({
    name = "controls",
})

main_tab:CreateToggle({
    name = "auto farm",
    flag = "auto_farm",
    value = false,
    callback = function(val)
        print("auto farm:", val)
    end,
})

main_tab:CreateSlider({
    name = "speed",
    range = {16, 200},
    increment = 1,
    value = 16,
    suffix = " studs/s",
    callback = function(val)
        print("speed:", val)
    end,
})

Window Configuration

Options available when calling slate:CreateWindow(options):

Property Type Default Description
name string "Slate" Title displayed in topbar and minimized pill.
subtitle string nil Secondary subtitle text.
icon number | string 136661212895058 Slate logo decal ID or Fluent icon name.
sidebarLayout boolean false false for modern top tabs, true for vertical sidebar.
theme string "Default" "Default", "Frost", "Rose", "Ember", "Cobalt", "Amethyst".

Tabs & Sections

Organize controls with tabs and labeled section headers:

LUAU 
local combat_tab = window:CreateTab({
    name = "combat",
    icon = "shield",
})

combat_tab:CreateSection({
    name = "aimbot options",
})

Buttons

Trigger actions and callbacks with clickable cards:

LUAU 
tab:CreateButton({
    name = "teleport to spawn",
    description = "instantly teleports character to spawn point",
    callback = function()
        print("teleporting...")
    end,
})

Toggles

Boolean switches with smooth animations, persistence flags, and lockable states:

LUAU 
local toggle = tab:CreateToggle({
    name = "kill aura",
    description = "automatically attacks nearby hostiles",
    flag = "kill_aura",
    value = false,
    callback = function(state)
        print("kill aura:", state)
    end,
})

toggle:Lock("Requires premium")
toggle:Unlock()

Sliders

Smooth numeric slider with range, precision, custom suffix, and live tooltips:

LUAU 
tab:CreateSlider({
    name = "hitbox expander",
    description = "adjusts enemy hitbox radius",
    flag = "hitbox_size",
    range = {2, 50},
    increment = 0.5,
    value = 10,
    suffix = " studs",
    callback = function(val)
        print("hitbox:", val)
    end,
})

Dropdowns

Supports both single-selection and multi-selection lists:

LUAU 
tab:CreateDropdown({
    name = "target bone",
    flag = "aim_bone",
    options = {"Head", "Torso", "HumanoidRootPart"},
    value = "Head",
    multiSelect = false,
    callback = function(selected)
        print("target bone:", selected)
    end,
})

tab:CreateDropdown({
    name = "esp filters",
    flag = "esp_filters",
    options = {"Players", "NPCs", "Items", "Chests"},
    value = {"Players", "Chests"},
    multiSelect = true,
    callback = function(selectedTable)
        print("filters:", table.concat(selectedTable, ", "))
    end,
})

Inputs & Keybinds

Textboxes and customizable keybinding controls:

LUAU 
tab:CreateInput({
    name = "custom message",
    placeholder = "enter text...",
    flag = "custom_msg",
    callback = function(text)
        print("input text:", text)
    end,
})

tab:CreateKeybind({
    name = "toggle menu",
    flag = "menu_key",
    value = Enum.KeyCode.RightShift,
    hold = false,
    callback = function()
        print("keybind pressed")
    end,
})

Color Pickers

Full 2D gradient canvas, hue slider, and hex code support with live swatch previews:

LUAU 
tab:CreateColorPicker({
    name = "chams color",
    flag = "chams_col",
    color = Color3.fromRGB(255, 255, 255),
    callback = function(col)
        print("color updated:", col)
    end,
})

Progress & Console

Real-time visual progress bars and scrollable debug console logs:

LUAU 
local prog = tab:CreateProgress({
    name = "level exp",
    range = {0, 100},
    value = 45,
    showValue = true,
})

local console = tab:CreateConsole({
    name = "execution logs",
    text = "slate ready",
    height = 120,
})
console:Append("script loaded successfully")

Notifications & Toasts

Trigger non-intrusive alert toasts and popup dialogs. Notifications automatically default to the Slate logo with clean right-aligned text:

LUAU 
window:Notify({
    title = "slate",
    content = "notification triggered",
    duration = 3,
})

window:Toast({
    title = "saved",
    subtitle = "settings written to disk",
    duration = 2,
})
