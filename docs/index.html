Slate UI / Documentation

Slate UI Documentation

A modern, ultra-responsive monochrome UI library for Roblox with top pill navigation, left-to-right swipe transitions, and 1,200+ solid filled Fluent icons.

Overview

Slate provides a clean obsidian dark aesthetic with pure white accents, fluid swipe page transitions, custom icon colors, and universal executor compatibility.

Installation

Load Slate directly via HTTP using loadstring:

LUAU
local slate = loadstring(game:HttpGet("https://raw.githubusercontent.com/EORScopeZ/slatelib/main/Slate.lua"))()

Window Configuration

Create a master window with custom title, subtitle, icon, theme, and layout mode:

LUAU
local window = slate:CreateWindow({
    name = "slate",
    subtitle = "ui library",
    icon = 136661212895058,
    theme = "Default",
    sidebarLayout = false, -- false for top pill tabs, true for sidebar
})

Tabs & Sections

Organize controls cleanly using top pill navigation tabs and labeled sections. Pass solid filled Fluent icon names directly.

LUAU
local tab = window:CreateTab({
    name = "combat",
    icon = "sword", -- solid filled fluent icon
    iconColor = Color3.fromRGB(255, 255, 255),
})

local section = tab:CreateSection({
    name = "combat controls",
})

Buttons

Trigger actions on click with interactive feedback and custom icon colors.

LUAU
local button = tab:CreateButton({
    name = "kill aura",
    description = "automatically attack targets in range",
    icon = "crosshair",
    iconColor = Color3.fromRGB(255, 80, 80),
    callback = function()
        print("kill aura executed")
    end,
})

Toggles & Switches

Boolean switches with smooth sliding spring animations and flag persistence.

LUAU
local toggle = tab:CreateToggle({
    name = "auto parry",
    description = "automatically parries incoming projectiles",
    icon = "shield",
    flag = "auto_parry",
    value = false,
    callback = function(val)
        print("auto parry is now:", val)
    end,
})

Sliders

Draggable numeric sliders with range bounds, precision increments, and custom suffixes.

LUAU
local slider = tab:CreateSlider({
    name = "walkspeed",
    description = "adjust character speed",
    icon = "flame",
    flag = "speed_val",
    range = {16, 250},
    increment = 1,
    value = 16,
    suffix = " studs/s",
    callback = function(val)
        print("speed:", val)
    end,
})

Dropdowns

Single and multi-select accordion dropdowns with dynamic item insertion and removal.

LUAU
local dropdown = tab:CreateDropdown({
    name = "target mob",
    description = "select enemy entity",
    flag = "target_mob",
    options = {"bandit", "boss", "zombie", "pirate"},
    value = "bandit",
    multiSelect = false,
    callback = function(opt)
        print("selected mob:", opt)
    end,
})

Color Pickers

Color swatch with real-time RGB, HEX, and alpha transparency adjustment.

LUAU
local colorpicker = tab:CreateColorPicker({
    name = "esp chams color",
    description = "select highlight tint",
    icon = "palette",
    flag = "chams_color",
    color = Color3.fromRGB(0, 170, 255),
    alpha = 1,
    callback = function(col, alpha)
        print("color:", col, "alpha:", alpha)
    end,
})

Dynamic Modification API

Update any element dynamically without recreating UI instances:

LUAU
toggle:Set(true)
slider:Set(120)
dropdown:Set("boss")
dropdown:Refresh({"mob 1", "mob 2", "mob 3"})
dropdown:Add("mob 4")
dropdown:Remove("mob 1")
button:Lock("disabled during combat")
button:Unlock()

Notifications, Toasts & Popups

Communicate events to users using cards, bottom toasts, or interactive modal dialogs.

LUAU
window:Notify({
    title = "slate",
    content = "configuration applied successfully",
    icon = "shield",
    duration = 3,
})

window:Toast({
    title = "saved",
    subtitle = "profile saved to disk",
    duration = 2.5,
})
